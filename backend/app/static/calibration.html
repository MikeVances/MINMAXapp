🔬 Калибровка помещения

← На главную ⚙️ Настройки

Эта страница позволяет точно рассчитать теплопотери помещения и учесть дополнительный воздухообмен для газовых обогревателей открытого горения. Калибровка выполняется один раз, результаты используются для автоматического расчета минимальной вентиляции с учетом работы обогревателей.

Шаг 1: Размеры помещения

Введите габаритные размеры птичника. Объем будет рассчитан автоматически.

Объем помещения — м³
Площадь пола — м²

Шаг 2: Обогревательное оборудование

Укажите тип и общую мощность обогревателей. Для газовых обогревателей открытого горения система автоматически добавит воздух для горения (≈95 м³/ч на 100 кВт).

ℹ️ Справка по газовым обогревателям:
  • Расход природного газа: ~10 м³/ч на 100 кВт
  • Необходимый воздух для горения: ~9.5 м³ на 1 м³ газа
  • Итого: ~95 м³/ч воздуха на 100 кВт мощности

Шаг 3: Тест охлаждения (калибровка)

Инструкция:
1. Нагрейте помещение до желаемой температуры (например, 30°C)
2. Выключите обогрев и вентиляцию
3. Засеките время и замерьте температуру через 5-10 минут
4. Введите данные ниже для расчета коэффициента теплопотерь
